IMTK - simple C immediate mode GUI toolkit
==========================================

A very simple immediate mode GUI toolkit I wrote when I first read about the
idea of an immediate mode GUI in 2010 from Sol's tutorial: http://iki.fi/sol/imgui/

It has proven useful for simple widgets in many graphics programs I wrote over
the next 16 years, and since I keep coming back to it and copying the source
files from project to project, it's time to make a permanent public repo for
it: https://github.com/jtsiomb/imtk
